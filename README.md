## 1. Описание проекта

Разработан интеллектуальный чат-бот, который помогает пользователю быстро определить совместимость компонентов персонального компьютера.

В основе проекта лежит MLP (многослойный перцептрон) - нейросеть, обученная на данных о различных компонентах ПК. Модель анализирует характеристики компонента и предсказывает его совместимость с системой.

### 1.1. Ключевые возможности

- Поиск компонентов по названию, сокету или параметрам
- Проверка совместимости отдельных компонентов с указанием уверенности
- Проверка связки CPU + Материнская плата (команда pair)
- Группировка результатов по типам компонентов
- Интуитивно понятный интерфейс командной строки

### 2.3. Предобработка данных

Категориальные признаки преобразуются с помощью LabelEncoder:


| Признак | Исходное значение | Закодированное значение |
|---------|-------------------|-------------------------|
| Type    | COOLER            | 0                       |
| Type    | CPU               | 1                       |
| Type    | GPU               | 2                       |
| Type    | MB                | 3                       |
| Socket  | AM4               | 0                       |
| Socket  | AM5               | 1                       |
| Socket  | LGA1700           | 2                       |
| Socket  | PCIe x16          | 3                       |
| Socket  | Universal         | 4                       |


Числовые признаки нормализуются с помощью MinMaxScaler:


| Признак | Диапазон исходных значений | Диапазон после нормализации |
|---------|----------------------------|-----------------------------|
| TDP     | 0 - 263 Вт                 | 0 - 1                       |
| Price   | 2000 - 65000 руб           | 0 - 1                       |

## 6. Работа с чат-ботом
### 6.1. Команды


| Команда                              | Описание                                                     | Пример                               |
|--------------------------------------|--------------------------------------------------------------|--------------------------------------|
| `predict <название>`                 | Поиск и проверка совместимости компонента по названию        | `predict ryzen 5`                    |
| `predict <тип> <сокет> <TDP> <цена>` | Точная проверка совместимости по параметрам                  | `predict CPU LGA1700 65 14500`       |
| `pair cpu <название> mb <название>`  | Проверка совместимости связки процессора и материнской платы | `pair cpu "Ryzen 5 5600X" mb "B550"` |
| `more <тип>`                         | Показать все компоненты указанного типа из последнего поиска | `more CPU`                           |
| `types`                              | Показать список всех доступных типов компонентов             | `types`                              |
| `sockets`                            | Показать список всех доступных сокетов                       | `sockets`                            |
| `help`                               | Показать справку по всем командам                            | `help`                               |
| `exit`                               | Выйти из чат-бота                                            | `exit`                               |

## 7. Результаты и выводы
### 7.1. Реализованные функции
Предобработка данных - автоматическое преобразование категориальных и числовых признаков

Обучение MLP модели - нейросеть с архитектурой 4-64-32-16-1

Интеллектуальный поиск - поиск компонентов по названию, сокету, параметрам

Проверка совместимости - предсказание с указанием уверенности

Проверка связки CPU + MB - анализ совместимости двух компонентов

Удобный интерфейс - командная строка с интуитивными командами

### 7.2. Ограничения
Точность предсказаний зависит от качества и объёма данных

Модель проверяет компоненты индивидуально, а не в составе сборки

Требуется переобучение при добавлении новых данных

### 7.3. Перспективы развития
Проверка полных сборок ПК (CPU + MB + GPU + RAM + PSU)

Рекомендательная система - подбор компонентов под бюджет

Веб-интерфейс вместо командной строки

Интеграция с реальными магазинами для актуальных цен
